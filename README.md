# 찬양하는교회 웹앱

부천 찬양하는교회 성도를 위한 설치형 웹앱(PWA)입니다. 화면은 GitHub Pages 에서, 글과 주보 사진은 Supabase 서버에서 제공합니다.

## 들어 있는 기능

- 홈: 오늘의 말씀, 생명의 삶 QT 연결, 최근 주일예배, 교회 소식
- 설교: 유튜브 예배 영상 841개 (주일예배 / 주일저녁예배 / 금요심야기도회, 연·월별), 설교 노트
- 소식·주보·일정: 관리자가 앱에서 올리면 모든 성도에게 보입니다 (주보 사진 첨부 가능)
- 관리자 로그인, 글 올리기·지우기, 전체 내용 내려받기(백업)
- 새 글이 올라오면 종 모양에 점 표시
- 기도제목
- 예배 시간, 오시는 길, 새가족 안내
- 홈 화면 설치, 인터넷이 끊겨도 마지막으로 본 내용 표시

https://nstepanet.github.io/chanyang/

## 어디에 올려야 앱에 반영되나

이 앱은 저장소의 **`gh-pages` 브랜치**에 있는 파일로 서비스됩니다. `main` 브랜치에는 같은 파일의 사본이 있습니다.

- 파일을 고칠 때는 **`gh-pages` 브랜치**에 올려야 앱에 반영됩니다. (GitHub 화면 왼쪽 위의 브랜치 버튼에서 `gh-pages` 를 고른 뒤 파일을 수정하거나 올립니다.)
- `main` 에만 올리면 앱은 바뀌지 않습니다. 두 브랜치를 같은 내용으로 맞춰 두면 헷갈리지 않습니다.
- 올린 뒤 1~2분이면 주소에 반영됩니다.

## 휴대폰에 설치하는 방법

- 아이폰: Safari 로 주소를 연 뒤 공유 버튼 → "홈 화면에 추가"
- 안드로이드: Chrome 으로 주소를 연 뒤 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

## 내용 고치기

| 고칠 것 | 어디서 |
|---|---|
| 소식, 주보, 일정 | 앱에서 관리자로 로그인 → 글 올리기 |
| 공동 기도제목, 서버에 연결되지 않을 때 보여 줄 기본 글 | `data/content.json` |
| 예배 영상 목록 | `data/videos.txt` |
| 예배 시간, 오늘의 말씀, 지도 주소 | `app.js` 맨 위의 `SETTINGS` |
| 서버 주소와 공개용 키 | `config.js` |
| 교회 건물 사진 | `img/church-building.jpg` |

파일을 고친 뒤에는 `sw.js` 맨 위의 `VERSION` 값을 `v2`, `v3` 처럼 올려 주세요. 그래야 이미 설치한 휴대폰에도 새 화면 파일이 확실히 받아집니다. (`data/` 안의 파일만 고쳤다면 올리지 않아도 됩니다.)

### data/videos.txt 형식

`연월일:종류+영상ID,종류+영상ID;` 를 이어 붙인 한 줄입니다. 종류는 `A` 주일예배, `B` 주일저녁예배, `C` 금요심야기도회입니다. 영상 ID 뒤의 `!` 는 비공개 영상 표시입니다.

예: `261115:AnoUNXF2j-uY,BW8DSejnlh7c;` → 2026년 11월 15일의 주일예배와 주일저녁예배

## 서버 (Supabase)

### 파일 구성

| 파일 | 역할 |
|---|---|
| `config.js` | 서버 주소(Project URL)와 공개용 키(Publishable key). 둘 다 공개되어도 되는 값입니다. |
| `server.js` | 서버와 통신하는 코드 전부. 서버를 다른 것으로 바꾸면 이 파일만 다시 쓰면 됩니다. |
| `vendor/supabase.js` | Supabase 브라우저 라이브러리 (@supabase/supabase-js, MIT 라이선스) |
| `supabase/setup.sql` | 서버에 표·접근 규칙·사진 저장 공간을 만드는 설정 |

`sb_secret_` 로 시작하는 Secret key 와 Database Password 는 이 저장소 어디에도 넣지 마세요.

### 처음 설정하는 순서

1. Supabase 대시보드 → **Authentication → Users → Add user → Create new user** 에서 관리자 계정(이메일, 비밀번호)을 만듭니다. "Auto Confirm User" 는 켠 채로 둡니다.
2. **SQL Editor** 에 `supabase/setup.sql` 전체를 붙여 넣고 **Run** 을 누릅니다. 결과 표의 "관리자 계정"에 1번의 이메일이 보이면 끝입니다.
3. (권장) **Authentication → Sign In / Providers** 에서 "Allow new users to sign up" 을 끕니다. 관리자 말고는 계정이 필요 없기 때문입니다.

### 관리자를 추가하거나 빼기

1번처럼 계정을 먼저 만든 뒤 SQL Editor 에서 실행합니다.

```sql
select app_private.add_admin('새관리자@example.com');     -- 추가
select app_private.remove_admin('그만둘분@example.com');  -- 제외
```

### 누가 무엇을 할 수 있나

| | 글 읽기 | 글 올리기·지우기 | 사진 올리기·지우기 |
|---|---|---|---|
| 로그인하지 않은 성도 | 가능 | 불가 | 불가 |
| 관리자가 아닌 계정 | 가능 | 불가 | 불가 |
| 관리자 | 가능 | 가능 | 가능 |

이 규칙은 앱이 아니라 서버(데이터베이스)에서 지킵니다.

### 백업과 이사

- 앱의 **더보기 → 전체 내용 내려받기 (백업)** 으로 모든 글을 파일 하나로 받을 수 있습니다. 무료 요금제에는 자동 백업이 없으니 가끔 받아 두세요.
- 무료 요금제는 일주일 동안 사용이 없으면 프로젝트가 멈춥니다. 멈추면 Supabase 대시보드에서 다시 켜면 되고, 그동안 앱은 마지막으로 받아 둔 글을 보여 줍니다.
- 다른 서버로 옮길 때는 데이터베이스를 내보내고, `post-images` 저장 공간의 사진을 옮긴 뒤, `config.js`(같은 종류의 서버) 또는 `server.js`(다른 종류의 서버)를 바꿉니다.

## 아직 안 되는 것 (다음 단계에서 추가)

- 기도제목은 각자 휴대폰에만 저장되고 서로 나눠지지 않습니다.
- 실제 푸시 알림은 가지 않습니다. (앱을 열면 종 모양의 점으로 새 글을 알려 줍니다.)
- 새 예배 영상이 자동으로 추가되지 않습니다.

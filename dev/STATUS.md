- `dev/` 의 도구는 리눅스에서만 돌려 봤습니다. Windows 에서는 돌려 보지 못했습니다. 브라우저를 찾는 부분(`dev/preview/browser.mjs`)이 Windows 의 Chrome·Edge 경로를 제대로 찾는지 처음 돌릴 때 확인이 필요합니다.
- `npm run server-status` 는 가짜 서버로만 시험했습니다.

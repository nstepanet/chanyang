서버 설정 복사하기

브라우저의 자동 번역이 설정 내용을 바꾸지 못하도록, 단추로 원본을 그대로 복사합니다.
  1. 설정 내용을 불러오는 중입니다…
  2. Supabase SQL Editor 열기 (새 탭)
    주소가 열리지 않으면 Supabase 왼쪽 메뉴에서 SQL Editor 를 누르세요.
  3. SQL Editor 의 입력 칸을 한 번 누릅니다. 이미 적혀 있는 내용이 있으면 Ctrl+A 로 모두 고른 뒤, Ctrl+V 로 붙여 넣습니다.
  4. Run 을 누릅니다. 아래 결과 표에 글 개수와 관리자 계정이 나오면 성공입니다.
단추로 복사가 되지 않을 때
아래 칸을 한 번 누른 뒤 Ctrl+A, Ctrl+C 를 차례로 누르세요.

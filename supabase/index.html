서버 설정 복사하기

브라우저의 자동 번역이 설정 내용을 바꾸지 못하도록, 단추로 원본을 그대로 복사합니다.

3단계 · 화면 디자인

관리자가 앱의 더보기 → 화면 디자인에서 고른 디자인(밝은 화면 · 따뜻한 화면 · 클래식 화면)이 모든 성도의 휴대폰에 적용되게 하는 설정입니다. 실행해도 지금 보이는 화면과 글, 성도 명단은 그대로입니다.
  1. 설정 내용을 불러오는 중입니다…
  2. Supabase SQL Editor 열기 (새 탭)
    주소가 열리지 않으면 Supabase 왼쪽 메뉴에서 SQL Editor 를 누르세요.
  3. SQL Editor 의 입력 칸을 한 번 누릅니다. 이미 적혀 있는 내용이 있으면 Ctrl+A 로 모두 고른 뒤, Ctrl+V 로 붙여 넣고 Run 을 누릅니다.
  4. 아래 결과 표의 화면 디자인 칸에 밝은 화면이 나오면 성공입니다. 이제 앱에서 관리자로 로그인한 뒤 더보기 → 화면 디자인에서 디자인을 고릅니다. 다른 휴대폰은 앱을 다시 열 때 바뀝니다.
여러 번 실행해도 안전하고, 이미 고른 디자인은 바뀌지 않습니다. (다른 디자인을 고른 뒤에 다시 실행하면 결과 표에 그 디자인 이름이 나옵니다.)
단추로 복사가 되지 않을 때
아래 칸을 한 번 누른 뒤 Ctrl+A, Ctrl+C 를 차례로 누르세요.
앱을 거치지 않고 디자인 바꾸기
앱에서 바꿀 수 없을 때만 씁니다. 3단계를 실행한 뒤에, 단추로 복사한 한 줄을 SQL Editor 에 붙여 넣고 Run 을 누르세요. 휴대폰에서는 앱을 다시 열면 바뀝니다.
2단계 · 성도 승인 (이미 실행했습니다)
이 설정을 실행하는 순간부터, 승인받지 않은 휴대폰은 글과 주보 사진을 볼 수 없습니다. 관리자 로그인이 되는지 먼저 확인해 두세요.
이미 실행한 서버에서 다시 실행해도 안전합니다. 명단과 승인 기록, 켜고 끈 상태는 그대로 남습니다.
  1. Supabase 로그인 설정 열기 (새 탭)
    화면 위쪽에서 Allow new users to sign up 과 Allow anonymous sign-ins 두 가지를 켜고 저장합니다. 이미 해 두었으면 넘어갑니다.
  2. 설정 내용을 불러오는 중입니다…
  3. Supabase SQL Editor 열기 (새 탭)
    주소가 열리지 않으면 Supabase 왼쪽 메뉴에서 SQL Editor 를 누르세요.
  4. SQL Editor 의 입력 칸을 한 번 누릅니다. 이미 적혀 있는 내용이 있으면 Ctrl+A 로 모두 고른 뒤, Ctrl+V 로 붙여 넣고 Run 을 누릅니다.
  5. 아래 결과 표의 성도 승인 칸에 켜짐이 나오면 성공입니다. 이제 앱에서 관리자로 로그인한 뒤 더보기 → 성도 승인에서 승인번호를 보냅니다.
단추로 복사가 되지 않을 때
아래 칸을 한 번 누른 뒤 Ctrl+A, Ctrl+C 를 차례로 누르세요.
성도 승인을 잠시 끄거나 다시 켜기
문제가 생겨 예전처럼 누구나 볼 수 있게 되돌려야 할 때 씁니다. 단추로 복사한 한 줄을 SQL Editor 에 붙여 넣고 Run 을 누르세요. 명단과 승인 기록은 그대로 남습니다.
